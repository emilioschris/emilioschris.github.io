00 Design system

Style guide

Every colour, font and component that Field Notes is built from. They all live in shared/field-notes.css and shared/field-notes.js, so every project looks like it belongs. Flip the Day/Dusk switch at the top to see both modes.

01Colours

The six palette colours, then the job each one does. Dusk swaps in a warm charcoal and slightly lighter accents, keeping the same orange. The ratio shows how readable each colour is as text on the page background (4.5 or more is good for small text, 3 or more for large headings).

The Deep End

Seven prompts a day, the same for everyone. Give an answer nobody else would think of: the rarer it is, the deeper you dive.

How the depths work

Each prompt gives you 25 seconds. Type an answer and press Enter. A right answer ends the round; a wrong guess costs 3 seconds, and you can keep trying until the time runs out.

    Each prompt hides one Wreck: a real answer almost nobody thinks of. All seven are revealed at the end.
